An entry for the make.fun competition
[Seventeen Syllables of Debugging](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

`main.py` (Python 3.13, standard library only) writes one original haiku
about debugging — a breakpoint that never fires, stack traces scrolling
past midnight, and the quiet turn of realizing who wrote the bug — to
`/output/entry.txt` in exact 5-7-5 syllable shape.

Run locally:

```sh
OUTPUT_DIR=/tmp/haiku-test python3 main.py
cat /tmp/haiku-test/entry.txt
```
